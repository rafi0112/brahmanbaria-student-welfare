BRAHMANBARIA IMAGE PACK — DOWNLOAD TOOL

This ZIP contains a downloader that collects up to 30 images from Wikimedia Commons categories related to Brahmanbaria, Bangladesh.

HOW TO USE
1. Extract this ZIP.
2. Open Command Prompt/Terminal in the extracted folder.
3. Run:
   python download_images.py
   or:
   python download_images.py --limit 30
4. It creates a folder named `brahmanbaria_images` containing the images, README.txt, and attribution.csv.

IMPORTANT
- This ZIP does not bundle other creators' copyrighted images. The script downloads them directly from Wikimedia Commons when you run it.
- Image licences vary. Read attribution.csv and open each source_page before using an image on a public/commercial website.
- Some licences require attribution and may require ShareAlike for adapted images.
- Only use photos whose exact place and caption suit your website; don't label generic scenery as a specific landmark.
- Official district tourist spot listing: https://brahmanbaria.gov.bd/pages/tourist-spot
- Wikimedia Commons category: https://commons.wikimedia.org/wiki/Category:Brahmanbaria
- Nature photos: https://commons.wikimedia.org/wiki/Category:Nature_of_Brahmanbaria_District
